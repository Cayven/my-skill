# 「线」关联模式参考

把「点」拆出来后，用以下模式把信息点两两/多两串联，形成有意义的关联线。每条线都要能说清「A 和 B 为什么有关」。

## 模式一：起源→演化
从一个元素的起源出发，追踪它如何演变到现在的形态。
- 例：马术服（贵族运动）→ 猎装夹克 → 现代风衣的肩章/腰带设计
- 例：军装 M65 野战夹克 → 街头工装风 → 奢侈品秀场的改良版

## 模式二：功能→符号
一件衣服最初的实用功能，如何演变成文化符号/风格标签。
- 例：牛仔布（矿工耐磨工装）→ 青春反叛符号 → 高端时尚面料
- 例：格纹（苏格兰氏族标识）→ 学院风 → 朋克改造（安全别针+格纹裙）

## 模式三：地域→风格迁移
一个地区的文化元素如何被另一个地区吸收、改造。
- 例：中国旗袍立领/盘扣 → 欧美设计师的「东方风」系列 → 新中式日常穿搭
- 例：日本和服宽袖/腰带 → 西方的浴袍式大衣（robe coat）

## 模式四：艺术→服装
艺术流派/运动如何影响服装设计语言。
- 例：包豪斯（几何、功能主义、三原色）→ 极简主义时装 → 结构感剪裁
- 例：印象派（朦胧色彩、光影）→ 印花雪纺、渐变染色

## 模式五：音乐→着装
音乐流派与标志性着装风格的共生关系。
- 例：爵士 → 宽松西装、礼帽、随性优雅
- 例：朋克 → 铆钉、破洞、皮衣、对抗性搭配
- 例：嘻哈（90s）→ oversize、大金链、运动品牌混搭

## 模式六：职业/阶层→日常化
特定职业或阶层的制服如何进入日常穿搭。
- 例：水手服（海军）→ 学院风连衣裙 → 条纹元素普及
- 例：芭蕾练功服（舞者）→ 芭蕾平底鞋、绑带元素、柔美学
- 例：僧侣袍 → 极简长款、禁欲风、大地色系

## 模式七：色彩→意象联想
把配色抽象成自然/场景意象，为搭配提供画面感依据。
- 例：蓝+白 → 蓝天/湖泊/白云 → 清爽度假感
- 例：棕+米+绿 → 森林/泥土/苔藓 → 大地系自然感
- 例：黑+红 → 暗夜/火焰 → 强烈戏剧感
- 例：灰+粉 → 水泥/樱花 → 都市柔和感

## 关联质量判断
- 好的线：有历史/文化/功能依据，能说出「为什么」。
- 弱的线：只是「我觉得它们搭」，没有依据——这种可以保留为个人直觉，但要和有据关联区分开。
- 一条线可以继续延伸：马术→宫廷→洛可可→繁复刺绣→现代品牌的宫廷风秀场，这就从「线」长成了「网」的一部分。
